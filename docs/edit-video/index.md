# Edit Video dengan Claude Code

Tutorial ni untuk kau yang **belum ada Claude Code** dan **belum ada akaun GitHub**. Kita mula dari kosong.

## Apa kau akan dapat

Lepas habis, kau boleh taip arahan biasa macam ni, dan Claude yang buat kerja edit:

> "Potong video `rakaman.mp4` dari minit 0:30 sampai 2:15, lepas tu resize jadi 9:16 untuk TikTok."

## Apa kau perlu sediakan

- Komputer Windows atau Mac
- Internet
- Email (untuk daftar akaun)
- Langganan **Claude berbayar** (Pro atau Max). Claude Code tak boleh guna dengan akaun percuma.
- Satu video pendek untuk dicuba

!!! info "Takut terminal?"
    Kau akan guna terminal (skrin hitam yang kau taip arahan). Jangan risau, setiap arahan aku bagi siap untuk copy-paste. Kau tak perlu faham semuanya.

## Peta perjalanan

| Step | Apa kita buat | Anggaran masa |
|---|---|---|
| 1 | Buat akaun GitHub | 5 minit |
| 2 | Pasang Git & GitHub CLI | 10 minit |
| 3 | Pasang Claude Code | 10 minit |

| 5 | Buat repo & folder kerja | 5 minit |
