# Edit Video dengan Claude Code, Guna Telefon Sahaja

Tutorial ini untuk anda yang **tiada komputer**, **belum ada Claude**, dan **belum ada akaun GitHub**. Semuanya dibuat dari telefon, bermula dari kosong.

## Apa yang anda akan dapat

Selepas selesai, anda boleh menaip arahan biasa seperti ini di telefon, dan Claude yang melakukan kerja edit:

> "Potong video `rakaman.mp4` dari minit 0:30 sehingga 2:15, kemudian resize jadi 9:16 untuk TikTok."

## Bagaimana ia berfungsi

Claude Code di telefon berjalan di **awan (cloud)**, bukan di dalam telefon anda. Jadi telefon hanya menjadi remote. Kerja berat dilakukan oleh komputer Claude di atas talian, dan alat edit video (ffmpeg) sudah tersedia di sana.

1. **Anda** muat naik video ke repo GitHub
2. **Anda** beri arahan kepada Claude melalui aplikasi
3. **Claude** edit video di cloud, kemudian simpan hasilnya ke repo
4. **Anda** muat turun video yang siap ke telefon

## Apa yang perlu disediakan

- Telefon (iPhone atau Android) dengan internet
- Alamat email
- Langganan **Claude berbayar** (Pro atau Max). Claude Code tidak boleh digunakan dengan akaun percuma.
- Satu video pendek untuk mencuba

!!! warning "Had saiz video"
    Muat naik video melalui browser GitHub dihadkan kepada **25MB** setiap fail. Jadi untuk permulaan, gunakan klip pendek (lebih kurang 10 hingga 30 saat). Bahagian bawah tutorial ini ada tip untuk video yang lebih besar.
