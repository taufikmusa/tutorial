# Ambil video yang siap

Claude menyimpan hasil kerja di GitHub, bukan terus di dalam galeri telefon anda. Jadi kita muat turun dari sana.

## Cara 1: Muat turun dari cabang Claude

Claude biasanya menyimpan hasil kerja dalam **cabang (branch)** berasingan, dengan nama bermula `claude/`.

1. Buka repo anda di browser: `github.com/<username anda>/video-saya`
2. Tekan menu cabang (biasanya tertulis **main**) dan pilih cabang yang bermula `claude/`
3. Buka folder `siap`
4. Tekan nama video. Anda boleh menontonnya terus di situ.
5. Tekan ikon **Download** (anak panah ke bawah) untuk simpan ke telefon

## Cara 2: Gabungkan ke main

Jika anda mahu video siap berada di cabang utama, minta Claude:

```text
Buat pull request untuk perubahan ini ke main.
```

Kemudian buka pull request tersebut di GitHub dan tekan **Merge pull request**.

!!! success "Tahniah!"
    Anda kini boleh mengedit video hanya dengan telefon. Mulai sekarang: muat naik video baharu ke repo, buka tab **Code**, dan beritahu Claude apa yang anda mahu.

## Selepas ini

- Cuba minta Claude menambah subtitle atau menukar kelajuan video
- Minta Claude menulis fail `CLAUDE.md` yang mengandungi arahan tetap anda (contohnya format TikTok kegemaran). Claude akan membacanya setiap kali sesi baharu bermula, jadi anda tak perlu mengulang arahan.
