# Edit Video dengan Claude Code

Tutorial ini untuk anda yang **belum ada Claude Code** dan **belum ada akaun GitHub**. Jangan risau, kita mulakan dari kosong.

## Apa yang anda akan dapat

Selepas selesai, anda boleh taip arahan biasa seperti ini, dan Claude yang akan buat kerja edit:

> "Potong video `rakaman.mp4` dari minit 0:30 sehingga 2:15, kemudian resize jadi 9:16 untuk TikTok."

## Apa yang perlu disediakan

- Komputer Windows atau Mac
- Sambungan internet
- Alamat email (untuk daftar akaun)
- Langganan **Claude berbayar** (Pro atau Max). Claude Code tidak boleh digunakan dengan akaun percuma.
- Satu video pendek untuk mencuba

!!! info "Takut dengan terminal?"
    Kita akan guna terminal, iaitu skrin hitam tempat anda menaip arahan. Tak perlu risau. Setiap arahan saya sediakan siap untuk copy-paste, dan anda tak perlu faham semuanya.

## Peta perjalanan

| Langkah | Apa yang kita buat | Anggaran masa |
|---|---|---|
| 1 | Buat akaun GitHub | 5 minit |
| 2 | Pasang Git & GitHub CLI | 10 minit |
| 3 | Pasang Claude Code | 10 minit |
| 4 | Pasang ffmpeg (enjin edit video) | 5 minit |
| 5 | Buat repo & folder kerja | 5 minit |
| 6 | Edit video pertama | 10 minit |
| 7 | Simpan kerja ke GitHub | 5 minit |
