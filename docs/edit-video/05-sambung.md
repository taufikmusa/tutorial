# Sambung Claude ke GitHub

Sekarang kita benarkan Claude mengakses repo anda.

1. Buka aplikasi **Claude**, kemudian pergi ke tab **Code**
2. Tekan untuk **menyambung ke GitHub** (Connect GitHub)
3. Browser akan terbuka. Log masuk ke GitHub jika diminta, dan tekan **Authorize**
4. Pasang **Claude GitHub App** apabila diminta. Pilih akaun anda, dan pada bahagian repositori, pilih **Only select repositories**, kemudian pilih `video-saya`. Tekan **Install**.
5. Kembali ke aplikasi Claude. Pilih repo **video-saya** untuk memulakan sesi baharu.

!!! tip "Kenapa pilih repo tertentu sahaja?"
    Lebih selamat. Claude hanya boleh melihat repo `video-saya`, bukan semua repo anda.

!!! success "Anda berjaya jika"
    Anda nampak ruangan sembang untuk sesi baharu, dengan nama repo `video-saya` kelihatan.
